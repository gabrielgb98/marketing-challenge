# Marketing Challenge

Juego de repaso de Principios de Marketing por equipos.

## MVP
- Un representante y un dispositivo por equipo; nombre personalizado.
- Sala con código de acceso, controlada por docente.
- Hasta 30 equipos, preguntas de opción múltiple con una sola respuesta correcta.
- Temporizador, puntos automáticos, ranking por ronda y podio final.
- Preguntas teóricas y casos prácticos; banco de preguntas pendiente de validación.

## Desarrollo previsto
Next.js + Supabase Realtime + Vercel. No se debe simular multijugador mediante estado local: los equipos deben compartir una partida persistente.
